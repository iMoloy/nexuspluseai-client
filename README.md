# NexusPulse AI - Next-Gen Super-App Client 🎨⚡

The frontend web application for **NexusPulse AI** — an AI-Powered Gig, Rental & Escrow Financial Super-App Ecosystem.

## 🚀 Tech Stack & Design System

- **Framework & Language:** Next.js 16 (App Router), React, TypeScript
- **Styling & Motion:** Tailwind CSS, Framer Motion, Fontshare Typography (*General Sans* & *Satoshi*)
- **State Management & Fetching:** TanStack Query (`@tanstack/react-query`)
- **Toast Notifications:** `react-toastify`
- **Image Hosting:** ImgBB API & Unsplash Visual Assets
- **Icons:** Lucide React

## 💡 Key UI Features & Dashboards

1. **Interactive Escrow Wallet Dashboard:** Live Available & Escrow Hold Balance Cards, In-App Deposit Modal, and Real-time Financial Ledger.
2. **Smart Asset & Vehicle Rental Marketplace:** Category Filter Pills, Unsplash Visual Showcase Cards (Cars, Cameras, Drones, Workspaces), Security Deposit Badges, and Rental Booking Escrow Modal.
3. **Micro-Tasking Interactive Kanban Board:** Live Drag/Move Task Columns (`Open Gigs`, `In Progress`, `Under Review`, `Completed & Paid`), Freelancer Selection, Work Proof Submission & Escrow Payment Approval.
4. **AI Assistant & Dispute Mediator Modal:** Gemini AI Prompt Generator and AI Settlement Mediator Dialog.

## 🛠️ Installation & Setup

1. **Clone & Install Dependencies:**
   ```bash
   git clone https://github.com/iMoloy/nexuspluseai-client.git
   cd nexuspluseai-client
   npm install
   ```

2. **Development Server:**
   ```bash
   npm run dev
   ```

3. **Production Build:**
   ```bash
   npm run build
   npm start
   ```
